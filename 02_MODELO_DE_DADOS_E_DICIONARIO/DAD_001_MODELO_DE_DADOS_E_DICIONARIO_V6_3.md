# Modelo de Dados e Dicionário

## Princípio
A base operacional é a fonte estruturada para interface, cálculos, auditoria e BI futuro.

## Entidades centrais
Obras; Etapas; Serviços/Orçamento; Planejamento; Compras; Financeiro; Execução/Medições; Alterações; Pendências.

## Regra
Identificadores técnicos podem existir internamente; o usuário vê nomes reais e claros.
