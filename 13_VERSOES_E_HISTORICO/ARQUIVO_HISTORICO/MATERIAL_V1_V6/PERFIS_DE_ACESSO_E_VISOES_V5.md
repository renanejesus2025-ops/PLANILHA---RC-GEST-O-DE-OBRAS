# Perfis de Acesso e Visões — V5

## Perfis oficiais
### Administrador/Operador
É uma única função. Administra e opera o sistema, cadastra, lança, corrige, acompanha, configura o que estiver autorizado e executa auditorias.

### Cliente
Acessa uma visão gerencial restrita. Não edita a base operacional, fórmulas, configurações ou áreas técnicas.

## Matriz resumida
| Área | Admin/Operador | Cliente |
|---|---|---|
| Início/Obra | Edita | Consulta |
| Orçamento | Edita | Indicadores autorizados |
| Planejamento | Edita | Consulta |
| Compras | Edita | Consulta autorizada |
| Financeiro | Edita | Visão autorizada |
| Execução | Edita | Consulta |
| Alterações | Edita | Consulta autorizada |
| Pendências | Edita | Consulta selecionada |
| Auditoria | Executa | Sem acesso técnico |
| Configurações | Edita | Sem acesso |
| Base/Fórmulas | Protegido por regras | Sem acesso |

## Regra de segurança
Ocultar abas não é segurança suficiente. A solução combina interface por perfil, permissões, proteção de células/planilhas/arquivo e permissões do ambiente de armazenamento.
