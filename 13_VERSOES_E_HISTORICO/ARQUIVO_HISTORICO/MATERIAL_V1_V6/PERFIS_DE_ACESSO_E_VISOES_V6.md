# Perfis de Acesso e Visões — V6

## Perfil 1 — Administrador/Operador
Uma única função. Pode administrar e operar os módulos autorizados, cadastrar, lançar, corrigir, acompanhar, configurar e executar auditorias.

## Perfil 2 — Cliente
Perfil predominantemente consultivo. Visualiza a visão gerencial e somente as informações autorizadas. Não edita base operacional, fórmulas, configurações ou áreas técnicas.

## Matriz resumida

| Área | Administrador/Operador | Cliente |
|---|---|---|
| Início/Obra | Edita | Consulta |
| Orçamento | Edita | Indicadores autorizados |
| Planejamento | Edita | Consulta |
| Compras | Edita | Consulta autorizada |
| Financeiro | Edita | Visão autorizada |
| Execução | Edita | Consulta |
| Alterações | Edita | Consulta autorizada |
| Pendências | Edita | Consulta selecionada |
| Auditoria | Executa | Sem acesso técnico |
| Configurações | Edita | Sem acesso |
| Base/Fórmulas | Protegido | Sem acesso |

## Princípio de segurança
Abas ocultas não são segurança suficiente. Usar interface por perfil, permissões, proteção de células/planilhas/arquivo e permissões do ambiente de armazenamento.
