# Arquitetura do Sistema

## Objetivo
Definir as camadas e responsabilidades do sistema.

## Camadas
1. Interface
2. Base de Dados
3. Motor de Cálculos
4. Controle e Proteção
5. Dashboard
6. Inteligência
7. Auditoria

## Princípio
A solução deve ser independente da plataforma de BI escolhida posteriormente.
